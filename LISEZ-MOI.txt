MOVE UP! — SPORTS ISLAND ADVENTURE — V1

INSTALLATION SUR GITHUB PAGES
1. Ouvrir le dépôt GitHub de l'application (ou créer un dépôt MOVE-UP).
2. Cliquer sur Add file > Upload files.
3. Déposer les fichiers index.html, style.css, app.js ET le dossier assets avec son contenu à la racine du dépôt.
4. Cliquer sur Commit changes.
5. Dans Settings > Pages, sélectionner Deploy from a branch / main / (root) si ce n'est pas déjà fait.
6. Le site sera accessible à https://VOTRE-PSEUDO.github.io/MOVE-UP/

IMPORTANT : le ZIP doit être décompressé avant le dépôt. Le fichier index.html doit se trouver à la RACINE du dépôt, et non dans un sous-dossier MOVE-UP-V1.

CONTENU
- Accueil inspiré de la maquette HD ; quatre îles cliquables.
- 16 missions originales : 4 activités EPS x 4 niveaux de classe.
- Choix 6e/5e/4e/3e ; correction pédagogique et transfert vers le terrain.
- Carnet EPS ; 4 badges d'île et 16 cartes ; récompenses en XP.
- Sauvegarde locale automatique dans le navigateur, sans compte.
- Interface mobile/tablette/ordinateur.

LIMITES V1
La maquette fournie est un visuel composite : l'image est utilisée en fond et en cadrages des îles, tandis que les contrôles sont de vrais éléments HTML. Pour une parfaite séparation décor/personnages, créer ultérieurement des assets individuels HD. Une mission est un quiz décisionnel, pas une simulation de geste ni une évaluation certificative.
Les questions sont des créations pédagogiques basées sur les intentions des champs d'apprentissage, et non des citations des attendus officiels.
